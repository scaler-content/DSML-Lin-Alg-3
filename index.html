Shifting 2D lines

Take a line through the origin, w₁x₁ + w₂x₂ + w₀ = 0. Shifting the line right by a units is the same as shifting the origin left by a units — the origin always moves in the opposite direction to the line's shift.

Shift right / up

Replace x₁ with (x₁ − a), or x₂ with (x₂ − a).

Shift left / down

Replace x₁ with (x₁ + a), or x₂ with (x₂ + a).

To move a line so it passes through an arbitrary point (a, b) instead of the origin: w₁(x₁ − a) + w₂(x₂ − b) + w₀ = 0. Expanding this shows the constant term −w₁a − w₂b + w₀ is just a new bias, w₀′ — shifting a line is really just updating the bias term.

A common mix-up: shifting a line right by a means replacing x₁ with (x₁ − a), not (x₁ + a). The "+a" version is what shifts the line left. Thinking in terms of "the origin moves opposite to the line" avoids the confusion.

Proof: the weight vector is always perpendicular to the line

Draw the weight vector [w₁, w₂] from the origin, and call the point where it meets the line d. Since d lies on the line, w₁d₁ + w₂d₂ + w₀ = 0. Because d points in the same direction as w, d̄ = k·ŵ for some constant k — substituting back and solving gives k explicitly.

Next, define y as the vector to the line's y-intercept. Using vector addition, ȷ̄ = d̄ + x̄, so x̄ = ȷ̄ − d̄ is the vector running along the line itself (from d to the y-intercept).

d̄ᵗ(ȷ̄ − d̄) = 0
Since the dot product of d (along w) and (y − d) (along the line) simplifies to exactly 0, the angle between them is 90°. That's the proof: the weight vector is always perpendicular to the line.

Numeric check

For the line 2x₁ + x₂ − 4 = 0 (w = [2, 1], w₀ = −4), confirm d̄ᵗ(ȷ̄ − d̄) comes out to zero.

Distance from the origin to a line

Using the vector d defined above, the distance from the origin to the line is ‖d̄‖. Solving algebraically (or geometrically, via cos θ = w̄ᵗx̄₀ / (‖w̄‖‖x̄₀‖) for any point x₀ on the line) gives a clean closed form:

d = −w₀ / ‖w̄‖
The sign of this distance tells us which side of the line the origin sits on — it isn't an error or a quirk, it's informative.

Distance from a point to a line

Shifting the origin to an arbitrary point x₀ turns this into the same problem as above: the vector d (from x₀, perpendicular to the line) is now the "local" weight vector for the shifted line. Working through the algebra (or the geometric proof via the two similar right triangles formed by x₀'s vector and the line) gives the general signed distance formula:

d = ( w̄ᵗx̄₀ + w₀ ) / ‖w̄‖

The coordinate-geometry route (substitute the point into the line equation, normalize by the line's coefficients) and the vector-algebra route compute exactly the same quantity.

Halfspaces

A line divides 2D space into two parts. Using the weight vector as the reference direction:

Positive halfspace

Points on the same side the weight vector points toward.

Negative halfspace

Points on the opposite side.

Verifying with the line x = 5 (weight vector along the x-axis): the point (6, 5) gives 6 − 5 = 1 (positive, right of the line); the point (2, 3) gives 2 − 5 = −3 (negative, left of the line).

The sign of the signed-distance formula is the halfspace test — exactly the mechanism used to classify any new point going forward.
